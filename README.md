1. Поиск товара
Пользователь вводит название игры в поиске например Dead by Daylight.
1)Клиент отправляет на сервер поисковый запрос
2)Сервер ищет подходящие товары
3)В ответ приходит список найденных товаров

3. Покупка товара
Пользователь выбирает товар и нажимает кнопку покупки
На сервер отправляется информация о выбранном товаре и заказе
1)Сервер проверяет, можно ли купить товар и доступна ли оплата
2)Если всё нормально, создаётся заказ
3)Если произошла ошибка, появляется сообщение об ошибке
ПРАКТИКА:
пропал интернет во время покупки
несколько раз нажали кнопку купить
какое-то поле оказалось пустым.
Результат: сайт показывает ошибку или не даёт продолжить покупку.

4. Вход в аккаунт
Пользователь вводит почту и пароль и нажимает войти
1)Данные отправляются на сервер
2)Сервер проверяет почту и пароль
3)Если данные правильные, пользователь входит в аккаунт
3)Если пароль неправильный, появляется ошибка
ПРАКТИКА:
Я выбрал покупку товара:
Нажал купить два раза
Выключил интернет и нажал купить
Оставил поле пустым и нажал продолжить
Результат: сайт показывает ошибку или не даёт продолжить покупку.
